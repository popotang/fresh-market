## 改版目标

原页面以“卡片墙”展示 27 个同步通道，信息密度高、视觉噪声大。新版改为监控台布局：

1. **头部**：标题、更新时间、自动刷新标识、刷新按钮，取消渐变与脉冲光效。
2. **指标条**：4 个紧凑指标（通道总数、运行正常、需要关注、24 小时内更新）合并为一条，用顶部色条区分状态。
3. **关注区**：有异常时只列前 3 个通道（名称、错误摘要、最近尝试时间），点击直接打开详情。
4. **通道表**：27 个通道改为表格，按“失败 → 中断 → 等待重试 → 未安排 → 部分完成 → 成功”排序；列出状态、最近成功、同步距今、入库/源行数（含进度条）、覆盖范围、更新时间。
5. **同步日志**：保留分页、筛选和展开详情；同步方式、覆盖范围、源窗口、错误信息收进展开行，减少主表宽度。
6. **详情抽屉**：新增“同步距今 / 行数 / 覆盖范围”摘要，其余字段保持。
